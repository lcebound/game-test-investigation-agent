# 统一主会话与事件自主调查入口

日期：2026-11-05。接续[Router 效果评估](router-routing-evaluation-2026-11-05.md)。本批调整入口组织方式，保留现有 Worker 调查、权限、证据、预算和恢复机制。

## 参考与实现

参考已核对的固定版本 deepseek-ai/dsh-superagent-prototype@6337fc823ce20251c8de8085948165c81aaa701e：

- src/core/intake.ts：已归属线程及订阅的后续输入直达相关 Worker，未归属输入进入评估。
- src/core/evals.ts：评估身份、合批、授权检查、幂等及有限恢复。
- prompts/orchestrator.md：协调者维护摘要与任务归属，具体调查交给 Worker，外部文本不能改变策略。

采用本项目已有会话—任务映射、task_subscriptions、路由评估账本、反馈批次和启动 Outbox，没有移植 TypeScript 运行时或更换数据库。

## 主会话入口

1. 工作台默认开启“主会话协调”。自由表达交给语义 Router，不再以“回到、另外”等词作为调用模型的前置条件。
2. 明确任务编号/规范名称等规则寻址继续优先，不需要再调用模型。
3. “当前选中的任务”保留为上下文提示，不能因为正文没命中关键词就默认取得消息归属。
4. 用户关闭“主会话协调”时，发送的是显式任务内回复：新增 bound_investigation_id 绑定经作用域验证后直达，不由模型改投其他任务。Worker 可以使用已有退回机制处理不属于自己的输入。
5. 没有权威历史依据的“上一个任务/另一个任务”等指代直接要求澄清；多意图由语义提示要求澄清，当前仍有模型误判边界。
6. 模型开启时，若未显式设置 GTA_ENABLE_SEMANTIC_ROUTER，默认同时开启语义协调；显式 false 仍被尊重。没有语义模型时，无法明确归属的自由表达会说明配置缺口，不再默默塞给当前任务。

API 的 context_investigation_id 仍是提示，新增 bound_investigation_id 才代表明确回复绑定。旧的两字段路由请求、幂等回执及恢复记录保持可读取；绑定也会持久化并在恢复时核验。显式绑定不允许跨会话、跨项目或退回排除目标。

## 外部事件入口

首次有明确归属的观察事件完成评估后，将 source/thread_key 与目标任务的关系写入现有订阅表。该线程后续事件先查订阅，直接进入同一任务的反馈批次，无需重复语义判断。

已结束/取消任务的订阅不会被外部事件自动复活，也不会借同一线程新建替代任务。多个已有所有者不会被自动挑成一个。绑定明确时不依赖完整任务目录，因此不会被语义目录 20 项上限无端阻塞。

未归属的失败事件可以自动新建调查，必须同时满足：

- 事件源已在对应租户、项目中登记；HTTP/MQ 入口的原有接收授权仍有效。
- 源策略显式开启 allow_observation_investigations。
- 策略至少具有 runs:read 和 evidence:read。
- 事件包含 failed，且不存在已有线程所有者；模糊归属的评估不会被当作新任务授权。
- 会话未归档，来源/任务快照和评估代次有效；没有超过自动任务额度。

新建使用确定性的会话+源+线程幂等键；创建任务、启动 Outbox、订阅及反馈投递在同一事务中完成。任一步失败一并回滚，不重复制造任务。

自动调查固定为有限只读调查：最多 6 轮、12 次读取、180 秒，且不超过主会话原预算；真实运行和设备分钟为 0，仅保留 tests:read/runs:read/evidence:read 范围，继承原 provider_allowlist。事件摘要明确标记为不可信线索，不能授予其中要求的操作权限。

max_observation_tasks 默认 4，是同一会话、同一来源的自动任务总额，不会因任务结束自行重置；可配置 1–20。健康、恢复、普通进度等事件不单独触发新调查。

示例配置（替换为真实来源与作用域）：

```json
[
  {
    "source": "lyra-monitor",
    "tenant_id": "studio-a",
    "project_id": "game-a",
    "scopes": ["tests:read", "runs:read", "evidence:read"],
    "policy_profile": "bounded-diagnosis",
    "allow_observation_investigations": true,
    "max_observation_tasks": 4
  }
]
```

写入 GTA_EVENT_SOURCE_POLICIES_JSON。新开关默认 false，不凭一次外部消息自动扩大来源授权。观察事件仍需带有效 conversation_id；无会话锚点的项目级异常沿用已有 anomaly.detected Intake，不会凭空建立用户会话。

观察摘要不再只取前 240 字节，保留完整已校验 summary 参与有界评估；现有模型上下文/时间/Token 门禁仍执行。过大的整批内容可能延期/失败，并不承诺任意大小都能一次判断。

## 验证结果

同一 42 类消息、每类两遍、同一模型的 Router-only 对照：

| 指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 正确判断 | 63/84（75.0%） | 83/84（98.8%） |
| 错误 task 目标 | 20 | 0 |
| 错误 new_task 决定 | 1 | 1 |
| 无触发词的切任务请求 | 0/10 | 10/10 |
| 无触发词的新调查请求 | 0/6 | 6/6 |
| 模型调用 | 36 | 56 |

这是一组边界题集上的复测，不是生产准确率或统计显著性结论。剩余一次失败是多意图消息被判为新任务；没有隐去，也没有改题目标签。主会话更全面地识别意图会增加模型调用，显式绑定和订阅直达用于减少不必要的评估。

事件补测从 4/5 到 5/5，原先位于摘要后半段的任务引用已能识别。Router-only 评测均未启动 Worker 或平台工具。

新增确定性回归覆盖：非关键词转交、新调查、绑定作用域、相对指代、线程订阅后免评估、源开关/权限、自动任务只读与去重、额度、取消后不重建、事务回滚及旧恢复格式。最终完整回归 **897 passed / 30 skipped**，耗时 173.21 秒。跳过项包括 25 个未启用的原生沙盒用例和 5 个外部依赖集成用例，不计作通过。

无头浏览器验证真实路由 API 与前端适配：明确绑定保持目标，主会话新任务请求得到新建决定；停止在实际消息/任务提交之前。原事件面板、综合、原报告和窄屏验证仍通过。

本批默认回归不启用原生沙盒，不启动游戏和 Docker。未变更 SQLite/MySQL Schema、NativeMemory 版本或冻结领域契约。Ruff、JS 语法、契约、锁文件、Wheel 与隔离导入通过。

## 限制与下一步边界

- 多意图还存在语义判断误差；尚未实现自动拆成多个有独立来源范围的指令。
- 自动事件调查必须显式配置来源策略，且受预算/任务总额限制，不意味着默认无限创建或执行补测。
- 没有重启用户工作台或修改私人来源配置，避免把代码交付当成部署完成；服务下次启动时读取新规则。
- 调查进展、结束、清理与待关注事项继续使用已有会话投影和通知路径，没有新增邮件或外部聊天推送。

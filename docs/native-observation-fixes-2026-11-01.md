# 单题观察后的修复

日期：2026-11-01。对应[此前的真实流程观察](readonly-agent-observation-2026-11-01.md)。本轮按用户要求控制验证成本：不启动游戏、平台测试或真实模型调查，仅运行相关离线回归和静态检查，未重跑全量测试及真实依赖栈。

## 已完成

- **摘录记忆**：普通读取及原生工具返回的开头摘录现在也进入持久工作笔记，记录证据 ID、SHA-256、来源、字节偏移及部分覆盖标记。笔记总量仍限制为 6,000 UTF-8 字节；未命中的范围不能据此判定不存在。旧检查点恢复时补充原证据哈希，并从已落盘的读取结果恢复笔记。空字符串和空值查询统一缓存身份，避免重复扣读取预算。
- **收尾预算**：每次探索调用前，为下一次有限报告保留 token 与费用空间。报告请求最多使用 24,576 字节的保守输入封套（窗口更小时随之缩小），另加已配置输出上限；按整个封套预留，允许后续摘录增长。预留在数据库事务内检查，不计为实际消费；未结算的调用仍保留原预订额度。预算不足以支持探索和收尾时，立即使用问题、计划、摘录及近期反馈构造报告请求，禁用额外读取。继续保留保守 UTF-8 字节估算，没有用未经验证的字符/token 比率放宽限额。
- **失败状态**：没有生成有效诊断的兜底报告和调查状态改为 `failed`，摘要明确说明未形成调查结论，并给出排除执行障碍的建议。新增业务结果事件，避免把没有 Python 异常等同于调查成功。有效但受证据限制的诊断仍可为 `completed/inconclusive`。
- **响应处理**：结算事件记录供应商 `finish_reason` 和 reasoning token 数，不保存推理正文。`length` 响应整批工具均不执行，最多进行一次有预算约束的恢复；内容过滤、鉴权和配置错误保留独立错误分类。供应商扩展字段投影修复继续保留严格参数及权限校验。
- **检索指引**：明确要求大 JSON 按问题中的断言、失败、清理、恢复字段定向搜索，找到所需信息后更新计划并报告；未覆盖分页必须说明。上下文裁剪记录前后大小、保留工具消息和笔记数量。

本机已授权的 DeepSeek 配置调整为窗口 32,768、输出上限 4,096、`thinking.type=disabled`，凭据保持不变。这是该本地配置的选择，未给所有供应商强加思考模式参数；重新启用需要思考字段往返的模式仍需实现相应供应商协议。

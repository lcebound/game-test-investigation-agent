# LLM 初步调查计划

原生 MCP 调查在读取证据前，由模型通过 `agent_update_plan` 提交 3–5 步计划。每步说明待验证问题、所需证据和完成条件。首次计划和第一次读取可放在同一次响应中顺序执行，后端拒绝跳过计划的读取请求。

后续通过当前版本号和步骤 ID 增量更新，后端保留未变化字段，再校验合并后的完整计划。完成步骤必须关联本次调查的可读证据并写出结果；受阻或跳过必须说明原因。计划不扩大工具权限，不修改平台工具的原始 Schema，不增加预算，反复修改计划也不能重置无进展检测。

计划事件独立持久化，工作检查点与固定上下文保留当前版本，重启时以最新计划事件为准。对话展示初版与调整原因，调查面板展示步骤、完成条件、结果及证据链接。历史调查不会补造计划，停止时未完成步骤保留原状态。

报告阶段只保留更新计划和提交报告，不再允许平台或证据读取。修订采用增量字段，避免模型完整重发计划时遗漏字段、增加输出或占用修正轮次。校验错误包含字段路径，但不回显提交数据。

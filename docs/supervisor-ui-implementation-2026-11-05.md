# 参考 Super-agent 的监督式前端重构

日期：2026-11-05。

## 上游确有前端

固定参考版本 deepseek-ai/dsh-superagent-prototype@6337fc823ce20251c8de8085948165c81aaa701e。

- [Panel 设计与行为](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/6337fc823ce20251c8de8085948165c81aaa701e/docs/005-panel.md)：优先回答“现在需要我吗”，其次是系统情况，再追溯单项工作的历史；概览、来源、触发、评估、执行和设置按概念分开。
- [前端依赖与入口声明](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/6337fc823ce20251c8de8085948165c81aaa701e/package.json)：它是 DeepSeek Harness 的 Web 面板，依赖 DSH 的界面与布局组件，不是一套可以直接替换本项目页面的独立前端。

本轮参考其交互和信息分层，重写本项目的主界面布局、样式和监督控制器；复用现有认证请求、幂等发送、流更新、证据、报告和授权逻辑，没有移植 DSH 运行时。

## 新交互结构

| 入口 | 用户可以做什么 |
| --- | --- |
| 概览 | 先看需要关注的事项，再看最近结果和协调配置；没有待处理事项时安静显示空状态 |
| 主会话 | 在同一条时间线查看不同后台任务的目标、补充和报告，统一提出目标或补充线索 |
| 后台调查 | 分页查看当前主会话的任务，按需打开详情；停止操作明确绑定到所点击的调查，并要求确认 |
| 事件与判断 | 查看外部观察的归属状态、原文与处理入口，以及当前身份最近的路由决定 |
| 信息来源 | 查看当前项目配置的平台、事件源、自动只读调查授权和消息桥状态；不把“已配置”冒充“已连接” |

左侧保留主会话历史，底部统一输入始终可用。旧的任务选择器和高级操作移入详情，不要求用户先选任务才能说话。显式“回复此调查”才会关闭主会话协调并设置回复目标，可一键回到主会话。

调查详情改成按需打开的抽屉：平台、执行、交流与授权、证据分别查看。保留原有代码审批的完整代码/权限展示、原请求哈希、认证与授权入口，不用一个摘要替代用户真正需要批准的内容。

不再在主对话窗口堆积单个 Worker 的工具调用和内部决策；详细记录可在对应调查中查看。主会话显示确定性投影及原任务报告，不冒充已实现一个新的常驻 Router LLM 对话 Session。

## 代码落点

- workbench-supervisor.js：监督导航、概览/任务/来源、跨任务会话、详情打开、明确回复和异步结果作用域保护。
- workbench-supervisor.css：新的监督界面布局、抽屉、移动端和深色主题。
- index.html：主导航、概览区域、统一输入目的地和任务详情入口重构。
- workbench-ui.js：在权威会话状态刷新时通知监督界面；保留原有流订阅与草稿恢复。
- workbench.js：原消息渲染可定向输出到详情容器，复用既有审批、报告导出及证据逻辑。
- workspace.py：新增只读跨任务 activity 投影，补充安全的当前项目来源和协调配置元数据。

## 数据正确性与边界

新增 GET /v1/conversations/{id}/activity，先按认证租户/项目解析会话，再读取该会话任务及其调查链。每次最多扫描最近 20 次调查、每次调查最近 10 条补充，最多展示 100 条活动；超限显示更早记录提示，旧记录可在具体任务中查看。

只输出目标、补充与报告摘要、时间和来源身份，不返回完整 request.constraints 或 Worker 私有工作上下文。报告正文超过 2000 字符会明确标记截取，保留报告 revision/hash 及详情入口。路由决定只显示“建议新建/关联/需要澄清”，不将尚未执行的决定显示成已执行。

所有新异步读取都校验会话、身份代次、前端代次及请求序号；切换身份或新建会话时清空聚合数据、任务详情和打开的辅助对话框。详情与主会话不共用同一个消息容器。

来源页只展示当前项目的已登记来源。事件自动调查策略仍由现有服务端授权控制，没有在 UI 添加虚假的保存或全局暂停开关。后台调查列表按当前主会话过滤，不是整个服务全部项目的全局列表。

## 验证

- 新增 activity API 作用域与内容回归：包含同会话不同任务及其报告，不包含另一会话的数据；跨项目拒绝；长报告摘要标记。
- 真实无头浏览器：概览、后台任务、详情抽屉、交流与授权记录、跨任务主会话、来源、原事件/重试、任务综合及原报告链接通过。
- 深浅主题、390px 窄屏、无横向溢出、无页面 JS 异常通过；身份切换后无旧对话框或任务详情残留。
- Router 与明确绑定接口继续实际调用；浏览器检查在任务/消息真正提交之前停止，没有为验 UI 运行游戏或真实 Worker 调查。
- Ruff、Node 语法、冻结契约、Wheel 构建、隔离导入与锁文件检查通过。最终完整回归 **899 passed / 30 skipped**，耗时 177.52 秒；25 个原生沙盒用例与 5 个外部依赖用例未启用，不计为通过。

原生沙盒、外部平台和 Docker 不属于本轮 UI 验证，未为改页面重新运行这些环境。

## 文档核对与本批选择

当前仍未完成的主要项目包括：通用未归属事件合批、退回输入的语义再评估、Worker 跨进程执行所有权、通用 MCP 长操作、跨任务技术归纳，以及真实模型质量与成本评测。

本批先完成持久路由评估的后台到期恢复。它直接延续已实现的数据与代次约束，避免服务中断后遗留请求一直等待用户重发；没有为此引入新的 Agent SDK、消息队列或第二套调度数据库。

机制继续参考固定版本 deepseek-ai/dsh-superagent-prototype@6337fc823ce20251c8de8085948165c81aaa701e 的 [Evals.due/expire](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/6337fc823ce20251c8de8085948165c81aaa701e/src/core/evals.ts) 与 [Effects.dispatch/attempt/drain](https://github.com/deepseek-ai/dsh-superagent-prototype/blob/6337fc823ce20251c8de8085948165c81aaa701e/src/app/effects.ts)：宿主恢复到期工作，限制每次处理量，重新核验当前代次，并在退出时停止领取。实现仍为本项目的 Python 行为适配，没有复制上游运行时。

## 自动恢复怎样运行

启用语义路由时，API 生命周期默认启动 RouterRecovery。可通过 `GTA_ENABLE_ROUTER_RECOVERY=false` 单独关闭；原有 `GTA_ENABLE_MODEL`、`GTA_ENABLE_SEMANTIC_ROUTER` 仍需启用。默认配置不会调用模型，也没有主动修改本机私有配置。

恢复器使用已有 `GTA_DISPATCHER_POLL_SECONDS`，间隔最低 1 秒，每轮最多顺序处理 4 条记录；每条仍受原有模型并发、总超时、上下文与输出预算限制。存储扫描接口最多支持 16 条，不能无限增加批次。没有为每条积压请求同时创建后台任务。

扫描条件包括：

- 正在运行但占用已经过期；
- 可重试且距上次释放至少 5 秒；
- 会话未归档，且该请求尚无最终收据。

元数据扫描不读取消息原文。单条实际恢复时才按身份、代次和占用令牌读取原文，最多 40,001 字符以便识别超限。原文必须符合路由输入字段、长度、规范序列化与原哈希；不能通过修改存储正文替换用户意图。

恢复沿用原请求键、主体与会话对应的租户和项目。重新进入原有路由服务后，在事务内再次核验“当前代次仍是扫描时那一代、现在确实到期”，防止旧扫描抢占刚更新或刚释放的评估。

任务目录、终态、墙钟预算、策略指纹以及最终收据依旧按第十四批复核。最多初次评估加两次恢复，耗尽后形成澄清收据，不无限调用模型。

## 失败、关闭与投递边界

原文损坏、超限、字段不合法或哈希不匹配时，将该代次标记为不可用，保留原文供审计，不让坏记录持续占住队首。正常请求的故障仅延后处理，其他行仍可继续。错误处置也校验旧代次与占用令牌，不能把另一个执行者的新工作标成失败或释放。

会话归档后跳过，恢复会话后才重新纳入扫描。已存在收据的请求不再评估。其他执行实例先接手时本轮跳过，仍由原有数据库占用保证结果提交边界。

服务关闭时先取消恢复循环，再关闭工作流、Provider 和数据库。取消继续传播到当前评估，只释放本实例仍拥有的代次；重启后按延迟继续恢复。单轮存储故障会记录无正文的告警并重试，不使恢复任务悄悄退出。进程内保留运行状态与最近一轮计数，尚未新增公开运维查询接口。

后台恢复仅生成原请求的路由收据，不启动调查、不投递输入、不创建独立任务。浏览器或调用方再次使用原请求键时直接取得结果；实际发送仍通过原有鉴权和任务接口。新任务的构建、预算及测试条件不完整时，后台不能自行补出执行授权。

## 数据库与部署

- SQLite 迁移 23，为评估状态/到期时间及状态/更新时间增加扫描索引；
- MySQL 新增 `019_route_recovery_indexes.sql`，最低版本提高到 019；
- 不修改 018 及更早迁移，不新增业务表、依赖或冻结契约，不修改 NativeMemory 版本；
- MySQL 019 的索引 DDL 若部分成功后中断，迁移器会检查已有索引的完整列、前缀、唯一性和类型，定义一致时继续，定义冲突时明确失败。

SQLite 22 升级测试确认原请求、状态和占用不变。MySQL 的部分 DDL 恢复用替身验证，真实引擎仍需联调；主机时间同步及供应商推理无法保证恰好一次等边界继续见第十四批记录。

不应混用不识别评估占用的旧版本。本批没有重启用户现有服务，也没有直接升级正在使用的数据库。
